# 2026.8.76 — the conversion desk

Forge Exchange gains the half it did not have: a way to turn one coin you hold into another
without leaving the ecosystem, and a surface to do it on.

## The engine (micro-wallet, micro-ledger, micro-contracts, micro-activity, micro-notify)

- A **desk account** — `{ subject: 'exchange', assetCode, purpose: 'inventory', type: 'equity' }`.
  `equity` rather than `clearing` on purpose: `ledger_assert_no_overdraft()` returns *allow* for
  `clearing` before it ever reads `overdraft_allowed`, so a clearing desk could be drawn negative.
  `equity` falls through to `overdraft_allowed = false` and Postgres refuses the overdraw inside
  the entry's own transaction, rather than trusting the service to have checked first.
- `POST /v1/conversions/quote` prices a conversion without reserving anything, and says so.
- `POST /v1/conversions` performs one, idempotency key required.
- `GET /v1/conversions` and `GET /v1/conversions/:id` read them back.
- `POST /v1/admin/exchange-desk/funding` puts stock in the desk or takes it out — one route with
  `direction: 'in' | 'out'`, so the reversal is exercised by the same tests and the same
  idempotency discipline as the funding.
- **`desk_inventory_short` (409)** when the desk cannot cover the output. It is checked twice:
  before pricing, and again against the priced output. The refusal names no figure — an anonymous
  caller should not be handed a trading signal for the price of one request — but the operator's
  `GET /v1/admin/exchange-desk` does return it, because that audience is deciding whether to fund.
- New activity topic **`wallet.conversion.completed`**, which fills the `conversion` category that
  until now had no producer.

## The surface (micro-hub-api, micro-hub-web, micro-exchange-web)

- hub-api composes all five wallet routes plus `GET /v1/transfers`, forwarding micro-wallet's
  status and `{ error: { code, message, requestId } }` envelope untouched.
- hub-web gains **`/convert`**, in the account sub-navigation beside Wallet and Activity, and an
  overview row pointing at Forge Exchange.
- `wallet.tsx`'s "not composed" placeholder for transfers and conversions is **gone**, replaced by
  a real transfers panel. The note that survives is narrowed to the one real remaining gap:
  `POST /v1/transfers` takes a `toUserId` and nothing in the estate resolves an email to one, so
  adding a lookup would publish an account-existence oracle.
- exchange-web points at the desk from the foot of the swap page rather than growing a nav entry
  for an off-origin destination.

## What this release does not do

Nothing seeds the desk. `requireAdmin` is `kind === 'user' && roles.includes('admin')`, so no
service principal can fund it whatever scope it holds — that is deliberate, and it means the first
funding is an operator action rather than something a deploy does silently.
