# 2026.8.79

## The exchange desk is finally observable (micro-org#501)

Forge Exchange fills every conversion out of the platform's own stock, and that stock is funded by hand through a `requireAdmin` route. Until this release it could run to zero and **nothing anywhere would say so** — `convert` throws `desk_inventory_short` before the conversion route's counter runs, so even the refusal moved no series. The first party to learn the desk was empty was the user holding a 409 that deliberately does not explain itself.

**micro-wallet**

- `wallet_desk_inventory{asset}`, sampled in `beforeScrape`, in whole units — a Prometheus sample is a float64 and the desk's 2.84e22 wei is four orders of magnitude past the last integer one holds exactly. Ordered last in the hook: it is the only call there that dials another service, and `/metrics` swallows a throw and serves the previous values.
- `wallet_money_operations_total{route="conversion",outcome="desk_short"}` — only that one error code is caught and counted, so a user's own shortfall and a pricing outage do not fold into the series an operator pages on. No asset label, which is the same decision the 409 makes.

**micro-deploy**

- `ExchangeDeskInventoryLow` (sev 3, `for: 30m`) — `wallet_desk_inventory <= 0.1 * max_over_time(wallet_desk_inventory[30d])`. Relative because the assets share no unit and a common one would need a price oracle behind an alert threshold.
- `ExchangeDeskInventoryShort` (sev 2, `for: 0m`) — the only rule that can see an asset the desk holds no account in at all, where no balance row means no series and silence is indistinguishable from health.
- `runbooks/runbook-exchange-desk-inventory.md`, and promtool unit tests for both. The tests caught a defect in the first draft of the Low rule: written as a division it rendered the *ratio* in the summary and, because `0/0` is NaN, never fired on a desk that had been empty the whole window.

`fundDesk` stays `requireAdmin` and the top-up is not automated. Both fundings this estate has booked drew on a user's available balance, so a service principal able to call it would be a machine that can debit a real person without that person's session. The human gate was never the defect; the defect was that the human had no way to know they were needed.
